# AI Game Portfolio

AIと共に制作したゲームの展示室です。

トップページでは、制作したブラウザゲームをカード形式で一覧でき、検索欄から作品を探したり、各カードのボタンからそのまま遊んだり、コードを確認したりできます。

## 収録作品

- **ゲーム**：42作品（`index.html` から一覧・検索できます）
- **アプリ**：9作品（`apps.html` から一覧できます）

各作品は単体のHTMLファイルとして収録されているため、ブラウザで開くだけで動作します。

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | ゲーム一覧のトップページ |
| `apps.html` | アプリ一覧ページ |
| `games/` | ゲーム本体（HTMLファイル） |
| `apps/` | アプリ本体（HTMLファイル） |
| `game-data.js` | ゲーム用データ（SF世界観のカードデータなど） |
| `update_site.sh` ほか | サイト生成・更新用のスクリプト |

## 見方

1. `index.html` をブラウザで開く（公開URLがある場合はそちらから）
2. 検索欄で作品名を探す
3. カードの **Play** ボタンで作品を開く。**Code** ボタンでファイル名を確認できます

## 備考

- 作品の多くはAIとの共同制作で生まれた実験的な小品です。概要が未記載の作品も順次追加していく予定です。
